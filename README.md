## Aegis-Lam Lite v1.0.0-beta (Global Release)



Aegis-Lam Lite is a lightweight security sentinel designed to help protect remote work environments by detecting suspicious activity and supporting rapid response. This release introduces initial multilingual support and global deployment readiness.



### Network Configuration



For stable communication and telemetry, this version uses the following fixed ports. Please make sure your firewall allows these connections when deploying the software:- **Fixed Ports**: `8443`, `8080`, `9000`



### Key Features



- **Global Language Support**: Automatically detects the system locale (KOR/EN) to provide a native user experience.- **Real-time Process Monitoring**: Uses heuristic checks to detect unauthorized or unusual activity.- **Tamper Protection**: Includes safeguards designed to resist inspection and modification of the security core.- **Crash-Resistant Architecture**: Designed for stability with automated recovery behavior.



### Aegis-Lam PRO (Upcoming)



We are currently developing **Aegis-Lam PRO** for more advanced security requirements.- **Zeroing Function**: The PRO version will include a containment and reset feature for identified threats.- **Advanced Console**: Adds enhanced management capabilities for enterprise environments.



### Data Policy



- **Log Collection**: This software collects operational and activity logs to support vulnerability analysis, debugging, and stability improvements.- All collected data is used strictly to improve detection quality and system reliability.
